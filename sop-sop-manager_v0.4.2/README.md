# CRM 客户联系人收集 SOP 流程管理器 v0.4.2

这是本地静态版 SOP 流程管理器。当前版本保留分页演示、观看/开发模式、截图目录、JSON 导入导出，并新增开发模式下的步骤管理能力。

## 打开方式

直接双击 `index.html`，或用 Chrome 打开。

项目不依赖后端、不依赖数据库、不需要联网。

## 重要说明：数据来源

页面加载顺序仍为：

1. 浏览器本机保存 `localStorage`
2. `data.json`
3. `index.html` 内嵌数据

所以如果你在旧版本点过“保存到本机”，新版本打开后可能仍显示旧版本本机保存内容。顶部开发模式会显示数据来源，例如：

```text
开发模式 · 数据来源：localStorage
```

需要查看当前文件自带数据时，请先在开发模式点击“清空本机记录”。


## 图片目录

图片在：

```text
assets/screenshots/
```

如需替换图片，将 `assets/screenshots` 文件夹覆盖到新版同名位置即可。

`data.json` 为正式配置文件
